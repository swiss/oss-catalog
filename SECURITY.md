# Reporting a Vulnerability

If you discover a security vulnerability, please report it privately
using the **Security** tab of this GitHub repository.

Please include a description of the vulnerability and, if possible,
steps to reproduce it.

We aim to:

- Acknowledge your report within 7 days.
- Keep you informed about the status of your report.
- Let you know whether the vulnerability has been accepted or declined.

Please do not disclose the vulnerability publicly until it has been
addressed.

Thank you for helping us keep our software secure.
